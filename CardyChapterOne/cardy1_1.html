PROBLEM 1.1 · FORMALIZED SOLUTION

In this exercise, we map the occupation variables of a binary alloy to $s(r)\in\{+1,-1\}$, expand the Hamiltonian term by term, and align the written derivation with theorems checked by the Lean 4 kernel.

Written mathematical derivation Lean 4 formalization Formalization-scope note

1 · Define the binary-alloy Hamiltonian

Reduce the full system to the energy of each pair of sites

Written solution Model definition

Let $n_A(r),n_B(r)\in\{0,1\}$ indicate whether site $r$ is occupied by species $A$ or $B$. The binary-alloy Hamiltonian is

$$ \begin{aligned} H=\sum_{r,r'}\big[&J_{AA}(r-r')n_A(r)n_A(r')+J_{BB}(r-r')n_B(r)n_B(r')\\ &+J_{AB}(r-r')n_A(r)n_B(r')+J_{AB}(r-r')n_B(r)n_A(r')\big]. \end{aligned} $$

Lean uses the more general two-variable kernel $J(r,r')$. For a translation-invariant interaction, one may set $J(r,r')=V(r-r')$.

Lean 4 alloyHamiltonian
inductive Species
  | A | B
  deriving DecidableEq, Repr

abbrev Config (Site : Type*) := Site → Species

def alloyHamiltonian
    (JAA JBB JAB : Site → Site → ℝ)
    (σ : Config Site) : ℝ :=
  ∑ r : Site, ∑ r' : Site,
    (JAA r r' * nA (σ r) * nA (σ r')
    + JBB r r' * nB (σ r) * nB (σ r')
    + JAB r r' * nA (σ r) * nB (σ r')
    + JAB r r' * nB (σ r) * nA (σ r'))

[Fintype Site] makes the set of lattice sites finite, so the double finite sum is well-defined directly.

2 · Map $A/B$ occupation to Ising spins

$A\mapsto+1$，$B\mapsto-1$

Written solution Change of variables

Define $s(r)=+1$ for species $A$ and $s(r)=-1$ for species $B$. Then

$$n_A(r)=\frac{1+s(r)}{2},\qquad n_B(r)=\frac{1-s(r)}{2}.$$

This substitution is not an approximation: it is an exact identity for each species, and $s(r)^2=1$.

Species$s$$n_A$$n_B$
$A$$+1$$1$$0$
$B$$-1$$0$$1$
Lean 4 Proof by cases
def nA : Species → ℝ
  | .A => 1 | .B => 0

def nB : Species → ℝ
  | .A => 0 | .B => 1

def spin : Species → ℝ
  | .A => 1 | .B => -1

@[simp] theorem nA_eq_spin (x : Species) :
    nA x = (1 + spin x) / 2 := by
  cases x <;> norm_num [nA, spin]

@[simp] theorem nB_eq_spin (x : Species) :
    nB x = (1 - spin x) / 2 := by
  cases x <;> norm_num [nB, spin]

cases x checks the cases $x=A$ and $x=B$ separately; norm_num completes the numerical simplification.

3 · Term-by-term expansion and the local energy identity

Condense the four products into one reusable lemma

Written solution Algebraic core

Writing $s=s(r)$ and $s'=s(r')$, the four terms are

$$ \begin{aligned} J_{AA}n_An_A'&=\tfrac14J_{AA}(1+s+s'+ss'),\\ J_{BB}n_Bn_B'&=\tfrac14J_{BB}(1-s-s'+ss'),\\ J_{AB}n_An_B'&=\tfrac14J_{AB}(1+s-s'-ss'),\\ J_{AB}n_Bn_A'&=\tfrac14J_{AB}(1-s+s'-ss'). \end{aligned} $$

After summing them, the energy of each pair of sites becomes

$$ \frac14(J_{AA}+J_{BB}-2J_{AB})ss' +\frac14(J_{AA}-J_{BB})(s+s') +\frac14(J_{AA}+J_{BB}+2J_{AB}). $$
Lean 4 pair_energy_identity
lemma pair_energy_identity
    (a b c : ℝ) (x y : Species) :
      a * nA x * nA y
    + b * nB x * nB y
    + c * nA x * nB y
    + c * nB x * nA y
    =
      ((1 / 4 : ℝ) * (a + b - 2 * c))
        * spin x * spin y
    + ((1 / 4 : ℝ) * (a - b))
        * (spin x + spin y)
    + ((1 / 4 : ℝ) * (a + b + 2 * c)) := by
  simp only [nA_eq_spin, nB_eq_spin]
  ring
Correspondence: Set $a=J_{AA}(r,r')$, $b=J_{BB}(r,r')$, $c=J_{AB}(r,r')$, $x=\sigma(r)$, and $y=\sigma(r')$ to obtain the pairwise formula in the left pane.

4 · Read off the effective coupling, field, and constant

Collect the linear terms in the double sum into $\sum_r h(r)s(r)$

Written solution Standard Ising form
$$H=\sum_{r,r'}J(r,r')s(r)s(r')+\sum_r h(r)s(r)+C,$$
$$ \begin{aligned} J(r,r')&=\tfrac14\big(J_{AA}(r,r')+J_{BB}(r,r')-2J_{AB}(r,r')\big),\\ h(r)&=\tfrac14\sum_{r'}\big[J_{AA}(r,r')-J_{BB}(r,r')\\ &\hspace{5.5em}+J_{AA}(r',r)-J_{BB}(r',r)\big],\\ C&=\tfrac14\sum_{r,r'}\big[J_{AA}(r,r')+J_{BB}(r,r')+2J_{AB}(r,r')\big]. \end{aligned} $$

The field $h(r)$ receives contributions both when $r$ appears in the first argument and when it appears in the second. This is why the formula contains both $J(r,r')$ and $J(r',r)$.

Lean 4 effective parameters
noncomputable def effectiveCoupling
    (JAA JBB JAB : Site → Site → ℝ) (r r' : Site) : ℝ :=
  (1 / 4 : ℝ) * (JAA r r' + JBB r r' - 2 * JAB r r')

noncomputable def effectiveField
    (JAA JBB : Site → Site → ℝ) (r : Site) : ℝ :=
    (∑ r' : Site, (1 / 4 : ℝ) * (JAA r r' - JBB r r'))
  + (∑ r' : Site, (1 / 4 : ℝ) * (JAA r' r - JBB r' r))

noncomputable def effectiveConstant
    (JAA JBB JAB : Site → Site → ℝ) : ℝ :=
  ∑ r : Site, ∑ r' : Site,
    (1 / 4 : ℝ) * (JAA r r' + JBB r r' + 2 * JAB r r')

effectiveField_formula and effectiveConstant_formula separately prove that these definitions equal the expressions in the left pane.

5 · Rearrange the linear term

The step most easily omitted in a handwritten derivation

Written solution Exchange summation indices

Let $D(r,r')=J_{AA}(r,r')-J_{BB}(r,r')$. Then

$$ \begin{aligned} &\sum_{r,r'}\frac14D(r,r')\big(s(r)+s(r')\big)\\ &=\sum_r\left[\sum_{r'}\frac14D(r,r')+\sum_{r'}\frac14D(r',r)\right]s(r)\\ &=\sum_r h(r)s(r). \end{aligned} $$

In the second term, exchange the dummy indices $r\leftrightarrow r'$ and then factor out the common $s(r)$.

Lean 4 field_rearrangement
lemma field_rearrangement
    (D : Site → Site → ℝ) (s : Site → ℝ) :
    (∑ r : Site, ∑ r' : Site,
      (1 / 4 : ℝ) * D r r' * (s r + s r'))
    =
    ∑ r : Site,
      ((∑ r' : Site, (1 / 4 : ℝ) * D r r')
       + (∑ r' : Site, (1 / 4 : ℝ) * D r' r)) * s r := by
  classical
  -- Split s r + s r', then swap the indices in the second sum
  have hswap :
      (∑ r : Site, ∑ r' : Site,
        (1 / 4 : ℝ) * D r r' * s r')
      = ∑ r : Site, ∑ r' : Site,
        (1 / 4 : ℝ) * D r' r * s r := by

6 · Main theorem: the two Hamiltonians are exactly equal

Local algebraic identity + linear-term rearrangement

Written solution Conclusion

Substituting the preceding results back into the double sum gives

Exact mapping
$$ H_{\mathrm{alloy}}(\sigma) =H_{\mathrm{Ising}}\big(J_{\mathrm{eff}},h_{\mathrm{eff}},C,s_\sigma\big). $$

No approximation is involved, and no symmetry of $J_{AA}$, $J_{BB}$, or $J_{AB}$ is required. The equality holds for every configuration on a finite lattice.

Lean 4 alloy_eq_ising
theorem alloy_eq_ising
    (JAA JBB JAB : Site → Site → ℝ)
    (σ : Config Site) :
    alloyHamiltonian JAA JBB JAB σ
    =
    isingHamiltonian
      (effectiveCoupling JAA JBB JAB)
      (effectiveField JAA JBB)
      (effectiveConstant JAA JBB JAB)
      (spinConfig σ) := by
  rw [alloy_decomposition]
  unfold isingHamiltonian effectiveField
  rw [field_rearrangement]

alloy_decomposition applies the local identity to every pair of sites, while field_rearrangement converts the result into the standard Ising field term.

7 · Zero field and $\mathbb Z_2$ symmetry

The symmetry condition relevant to the phase transition

Written solution Physical condition

If $h(r)=0$ for every $r$, the Hamiltonian is invariant under the global spin flip

$$s(r)\longmapsto-s(r),\qquad H[-s]=H[s].$$

A simple sufficient condition is $J_{AA}(r,r')=J_{BB}(r,r')$. In that case, the effective coupling $J_{\mathrm{eff}}$ controls the ordering tendency and critical scale.

Important: In general, $h\neq0$ still gives an Ising Hamiltonian with an external field. However, the field explicitly breaks the $s\mapsto-s$ symmetry, so one cannot directly claim the same spontaneous-symmetry-breaking transition as in the zero-field Ising model.
Lean 4 zero field + spin flip
theorem effectiveField_zero_of_equal_interactions
    (JAA JBB : Site → Site → ℝ)
    (hEq : ∀ r r', JAA r r' = JBB r r') :
    effectiveField JAA JBB = fun _ => 0 := by
  funext r
  simp [effectiveField, hEq]

Formal conclusion and physical interpretation

Proved in Lean: On a finite lattice, the binary-alloy Hamiltonian is exactly equal, for every configuration, to an Ising Hamiltonian with the stated $J_{\mathrm{eff}}$, $h_{\mathrm{eff}}$, and $C$. Lean also proves the $\mathbb Z_2$ spin-flip symmetry at zero field.

Physical interpretation: When $h=0$ and the system satisfies the usual conditions required for Ising critical behavior—such as an appropriate dimension, short-range interactions, and a thermodynamic limit—the alloy's order–disorder transition may belong to the Ising universality class.

Scope of the proof: cardy1_1.lean does not formalize the thermodynamic limit, critical temperature, correlation length, or critical exponents. Therefore, membership in the Ising universality class is a physical inference built on the algebraic mapping, not a machine-checked theorem in this Lean file.
