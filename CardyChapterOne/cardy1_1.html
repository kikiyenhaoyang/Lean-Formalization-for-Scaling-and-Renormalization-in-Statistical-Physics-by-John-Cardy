1 · Define the species and their occupation/spin values

Lean begins with the local state space before introducing the lattice Hamiltonian

Written solution Basic data

A lattice site can contain one of two species, $A$ or $B$, define the corresponding set $\text{Species} = \{A, B\}$. Define the occupation numbers $$n_A, n_B :\text{Species} \to \{0, 1\}$$ and spin value $$s :\text{Species} \to \{-1, +1\}$$ by the following table:

$$ \begin{array}{c|ccc} \text{species} & n_A & n_B & s \\ \hline A & 1 & 0 & +1 \\ B & 0 & 1 & -1 \end{array} $$

These local definitions are the foundation for every later algebraic identity.

Lean 4 Species, nA, nB, spin
inductive Species
  | A
  | B
  deriving DecidableEq, Repr

/-- Occupation number n_A ∈ {0,1}. -/
def nA : Species → ℝ
  | .A => 1
  | .B => 0

/-- Occupation number n_B ∈ {0,1}. -/
def nB : Species → ℝ
  | .A => 0
  | .B => 1

/-- Spin representation:
    A ↦ +1,
    B ↦ -1.
-/
def spin : Species → ℝ
  | .A => 1
  | .B => -1

The Lean file first defines the two constructors A/B, then the occupation-number functions and spin representation.

2 · Prove the basic local identities

The occupation variables are rewritten exactly in terms of the spin variable

Written solution Exact identities

For either species, the occupation numbers satisfy

$$n_A=\frac{1+s}{2},\qquad n_B=\frac{1-s}{2}.$$

Two additional facts are recorded immediately:

$$s^2=1,\qquad n_A+n_B=1.$$

All four statements are exact identities, not approximations.

Lean 4 nA_eq_spin → nA_add_nB
@[simp]
theorem nA_eq_spin (x : Species) :
    nA x = (1 + spin x) / 2 := by
  cases x <;> norm_num [nA, spin]

@[simp]
theorem nB_eq_spin (x : Species) :
    nB x = (1 - spin x) / 2 := by
  cases x <;> norm_num [nB, spin]

@[simp]
theorem spin_sq (x : Species) :
    spin x ^ 2 = 1 := by
  cases x <;> norm_num [spin]

@[simp]
theorem nA_add_nB (x : Species) :
    nA x + nB x = 1 := by
  cases x <;> norm_num [nA, nB]

cases x checks the two species cases; norm_num closes the numerical goals.

3 · Lift the local spin map to a finite lattice configuration

Only after the local identities does the Lean file introduce lattice configurations

Written solution Configuration

Let the set of all sites be denoted by $\mathrm{Site}$. A binary-alloy configuration assigns a species to every site:

$$\sigma:\mathrm{Site}\to\{A,B\}.$$

The associated spin configuration is obtained pointwise:

$$s_\sigma(r)=s(\sigma(r))\in\{+1,-1\}.$$

The finite-lattice section assumes [Fintype Site], so all later sums are finite.

Lean 4 Config, spinConfig
section FiniteLattice

variable {Site : Type*} [Fintype Site]

/-- A configuration of the alloy. -/
abbrev Config (Site : Type*) := Site → Species

/-- The spin configuration associated to an alloy configuration. -/
def spinConfig (σ : Config Site) : Site → ℝ :=
  fun r => spin (σ r)

4 · Define the original binary-alloy Hamiltonian

The full energy is introduced after the state and configuration maps

Written solution Original model

For a configuration $\sigma$, the binary-alloy Hamiltonian is

$$ \begin{aligned} H_{\mathrm{alloy}}=\sum_{r,r'}\big[&J_{AA}(r,r')n_A(\sigma(r))n_A(\sigma(r'))\\ &+J_{BB}(r,r')n_B(\sigma(r))n_B(\sigma(r'))\\ &+J_{AB}(r,r')n_A(\sigma(r))n_B(\sigma(r'))\\ &+J_{AB}(r,r')n_B(\sigma(r))n_A(\sigma(r'))\big]. \end{aligned} $$

At this stage the interaction is represented by general two-variable kernels $$J_{AA},J_{BB},J_{AB}:\text{Site}\times\text{Site}\to\mathbb{R}.$$

Lean 4 alloyHamiltonian
/-! ## Original alloy Hamiltonian -/

/--
The original binary-alloy Hamiltonian

H =
  Σ_{r,r'} [
    J_AA(r,r') n_A(r)n_A(r')
    + J_BB(r,r') n_B(r)n_B(r')
    + J_AB(r,r') n_A(r)n_B(r')
    + J_AB(r,r') n_B(r)n_A(r')
  ].
-/
def alloyHamiltonian
    (JAA JBB JAB : Site → Site → ℝ)
    (σ : Config Site) : ℝ :=
  ∑ r : Site,
    ∑ r' : Site,
      (
        JAA r r' * nA (σ r) * nA (σ r')
        + JBB r r' * nB (σ r) * nB (σ r')
        + JAB r r' * nA (σ r) * nB (σ r')
        + JAB r r' * nB (σ r) * nA (σ r')
      )

5 · Prove the pair-energy identity

The handwritten term-by-term expansion becomes one reusable algebraic lemma

Written solution Algebraic core

Substituting $n_A=(1+s)/2$ and $n_B=(1-s)/2$ into one pair energy gives

$$ \begin{aligned} &a n_A(x)n_A(y)+b n_B(x)n_B(y)+c n_A(x)n_B(y)+c n_B(x)n_A(y)\\ &=\tfrac14(a+b-2c)s(x)s(y) +\tfrac14(a-b)(s(x)+s(y)) +\tfrac14(a+b+2c). \end{aligned} $$

Set $a=J_{AA}(r,r')$, $b=J_{BB}(r,r')$, $c=J_{AB}(r,r')$, $x=\sigma(r)$, and $y=\sigma(r')$ to obtain the pairwise alloy-to-Ising decomposition.

Lean 4 pair_energy_identity
/-! ## Local algebraic identity -/

/--
This is the algebraic calculation performed in the handwritten
solution, but reduced to a theorem about five real numbers.

It is the key local identity behind the alloy → Ising mapping.
-/
lemma pair_energy_identity
    (a b c : ℝ)
    (x y : Species) :
      a * nA x * nA y
    + b * nB x * nB y
    + c * nA x * nB y
    + c * nB x * nA y
    =
      ((1 / 4 : ℝ) * (a + b - 2 * c))
        * spin x * spin y
    + ((1 / 4 : ℝ) * (a - b))
        * (spin x + spin y)
    + ((1 / 4 : ℝ) * (a + b + 2 * c)) := by
  simp only [nA_eq_spin, nB_eq_spin]
  ring
Lean proof: rewrite with nA_eq_spin and nB_eq_spin, then close the polynomial identity with ring.

6 · Decompose the full alloy Hamiltonian

Apply the pair identity obtained in the previous lemma everywhere before converting the field term

Written solution Three-part decomposition

Applying the local identity to every pair gives

$$ \begin{aligned} H_{\mathrm{alloy}}(\sigma) =&\sum_{r,r'}\tfrac14\bigg[J_{AA}(r,r')+J_{BB}(r,r')-2J_{AB}(r,r')\bigg]s_\sigma(r)s_\sigma(r')\\ &+\sum_{r,r'}\tfrac14\big(J_{AA}(r,r')-J_{BB}(r,r')\big) \big(s_\sigma(r)+s_\sigma(r')\big)\\ &+\sum_{r,r'}\tfrac14\big(J_{AA}(r,r')+J_{BB}(r,r')+2J_{AB}(r,r')\big). \end{aligned} $$

This intermediate theorem intentionally leaves the linear term as a double sum.

Lean 4 alloy_decomposition
/-! ## The decomposition theorem -/

/--
First version of the main calculation:
the alloy Hamiltonian decomposes into

1. quadratic Ising term,
2. linear term,
3. constant term.
-/
lemma alloy_decomposition
    (JAA JBB JAB : Site → Site → ℝ)
    (σ : Config Site) :
    alloyHamiltonian JAA JBB JAB σ
    =
      (∑ r : Site, ∑ r' : Site,
        effectiveCoupling JAA JBB JAB r r'
          * spinConfig σ r
          * spinConfig σ r')
      +
      (∑ r : Site, ∑ r' : Site,
        (1 / 4 : ℝ)
          * (JAA r r' - JBB r r')
          * (spinConfig σ r + spinConfig σ r'))
      +
      effectiveConstant JAA JBB JAB := by
  classical
  unfold alloyHamiltonian
    effectiveCoupling
    effectiveConstant
    spinConfig
  simp_rw [pair_energy_identity]
  simp only [Finset.sum_add_distrib]

simp_rw [pair_energy_identity] applies the local identity throughout the finite double sum.

7 · Rearrange the linear term into a one-site field

The second spin in the pair sum is handled by exchanging dummy indices

Written solution Index exchange

Let $D(r,r')=J_{AA}(r,r')-J_{BB}(r,r')$. The linear contribution is

$$\sum_{r,r'}\frac14D(r,r')\big(s(r)+s(r')\big).$$

Split the two terms, exchange $r\leftrightarrow r'$ in the second double sum, and factor out $s(r)$, then the linear contribution becomes:

$$ \sum_r\left[\sum_{r'}\frac14D(r,r')+\sum_{r'}\frac14D(r',r)\right]s(r). $$
Lean 4 field_rearrangement
/-! ## Rearranging the linear term -/

/--
Rearrange

Σ_{r,r'} 1/4 D(r,r') (s(r) + s(r'))

into

Σ_r h(r) s(r),

where

h(r) =
  Σ_{r'} 1/4 D(r,r')
  + Σ_{r'} 1/4 D(r',r).
-/
lemma field_rearrangement
    (D : Site → Site → ℝ)
    (s : Site → ℝ) :
    (∑ r : Site, ∑ r' : Site,
      (1 / 4 : ℝ) * D r r' * (s r + s r'))
    =
    ∑ r : Site,
      ((∑ r' : Site,
          (1 / 4 : ℝ) * D r r')
       +
       (∑ r' : Site,
          (1 / 4 : ℝ) * D r' r))
      * s r := by
  classical
  have hswap :
      (∑ r : Site, ∑ r' : Site,
        (1 / 4 : ℝ) * D r r' * s r')
      =
      ∑ r : Site, ∑ r' : Site,
        (1 / 4 : ℝ) * D r' r * s r := by
    rw [Finset.sum_comm]
  calc
    (∑ r : Site, ∑ r' : Site,
      (1 / 4 : ℝ) * D r r' * (s r + s r'))
        =
        (∑ r : Site, ∑ r' : Site,
          (1 / 4 : ℝ) * D r r' * s r)
        +
        (∑ r : Site, ∑ r' : Site,
          (1 / 4 : ℝ) * D r r' * s r') := by
            simp only [mul_add, Finset.sum_add_distrib]
    _ =
        (∑ r : Site, ∑ r' : Site,
          (1 / 4 : ℝ) * D r r' * s r)
        +
        (∑ r : Site, ∑ r' : Site,
          (1 / 4 : ℝ) * D r' r * s r) := by
            rw [hswap]
    _ =
        ∑ r : Site,
          ((∑ r' : Site,
              (1 / 4 : ℝ) * D r r')
           +
           (∑ r' : Site,
              (1 / 4 : ℝ) * D r' r))
          * s r := by
            rw [← Finset.sum_add_distrib]
            apply Finset.sum_congr rfl
            intro r _
            rw [← Finset.sum_mul, ← Finset.sum_mul]
            ring

Finset.sum_comm performs the crucial exchange of the finite summation indices.

8 · Define the effective Ising parameters and Ising Hamiltonian

Lean declares the target Ising model before proving the mapping

Written solution Target Ising model

Now we can define the effective coupling, field, and configuration-independent constant of the Ising model we map to by

$$ \begin{aligned} J_{\mathrm{eff}}(J_{AA},J_{BB},J_{AB},r,r')&=\tfrac14\big(J_{AA}(r,r')+J_{BB}(r,r')-2J_{AB}(r,r')\big),\\ h_{\mathrm{eff}}(J_{AA},J_{BB},r)&=\sum_{r'}\tfrac14\big(J_{AA}(r,r')-J_{BB}(r,r')\big) +\sum_{r'}\tfrac14\big(J_{AA}(r',r)-J_{BB}(r',r)\big),\\ C(J_{AA},J_{BB},J_{AB})&=\sum_{r,r'}\tfrac14\big(J_{AA}(r,r')+J_{BB}(r,r')+2J_{AB}(r,r')\big). \end{aligned} $$

The target Hamiltonian uses the sign convention

$$H_{\mathrm{Ising}}(J,h,C,s)=\sum_{r,r'}J(r,r')s(r)s(r')+\sum_r h(r)s(r)+C.$$
Lean 4 effectiveCoupling → isingHamiltonian
/-! ## Effective Ising parameters -/

/--
Effective Ising coupling

J(r,r') = 1/4 (J_AA + J_BB - 2 J_AB).
-/
noncomputable def effectiveCoupling
    (JAA JBB JAB : Site → Site → ℝ)
    (r r' : Site) : ℝ :=
  (1 / 4 : ℝ) *
    (JAA r r' + JBB r r' - 2 * JAB r r')

/--
Effective magnetic field.

This is written as two sums because this form is convenient
for the proof.  Below we prove that it is identical to

1/4 Σ_{r'} [
  J_AA(r,r') - J_BB(r,r')
  + J_AA(r',r) - J_BB(r',r)
].
-/
noncomputable def effectiveField
    (JAA JBB : Site → Site → ℝ)
    (r : Site) : ℝ :=
    (∑ r' : Site,
      (1 / 4 : ℝ) * (JAA r r' - JBB r r'))
  + (∑ r' : Site,
      (1 / 4 : ℝ) * (JAA r' r - JBB r' r))

/--
The configuration-independent constant C.
-/
noncomputable def effectiveConstant
    (JAA JBB JAB : Site → Site → ℝ) : ℝ :=
  ∑ r : Site, ∑ r' : Site,
    (1 / 4 : ℝ) *
      (JAA r r' + JBB r r' + 2 * JAB r r')

/--
Generic Ising Hamiltonian, following the sign convention
used in the problem:

H = Σ J(r,r') s(r)s(r') + Σ h(r)s(r) + C.
-/
def isingHamiltonian
    (J : Site → Site → ℝ)
    (h : Site → ℝ)
    (C : ℝ)
    (s : Site → ℝ) : ℝ :=
    (∑ r : Site, ∑ r' : Site,
      J r r' * s r * s r')
  + (∑ r : Site, h r * s r)
  + C

These definitions are introduced before the algebraic mapping lemmas, exactly as in the Lean source.

9 · Conclude exact equality with the Ising Hamiltonian

The decomposition theorem and field rearrangement are combined

Written solution Exact mapping

Using the field rearrangement in the preceding decomposition gives

Main result
$$H_{\mathrm{alloy}}(J_{AA},J_{BB},J_{AB},\sigma)=H_{\mathrm{Ising}}\big(J_{\mathrm{eff}},h_{\mathrm{eff}},C,s_\sigma\big).$$

The equality is exact for every configuration on the finite lattice.

Lean 4 alloy_eq_ising
/-! -! ## Main theorem -/

/--
The binary-alloy Hamiltonian is exactly an Ising Hamiltonian
with the stated effective coupling, field, and constant.
-/
theorem alloy_eq_ising
    (JAA JBB JAB : Site → Site → ℝ)
    (σ : Config Site) :
    alloyHamiltonian JAA JBB JAB σ
    =
    isingHamiltonian
      (effectiveCoupling JAA JBB JAB)
      (effectiveField JAA JBB)
      (effectiveConstant JAA JBB JAB)
      (spinConfig σ) := by
  rw [alloy_decomposition]
  unfold isingHamiltonian effectiveCoupling effectiveField effectiveConstant
  rw [field_rearrangement]

The proof uses alloy_decomposition first and field_rearrangement last.

10 · Derive zero field and global ℤ₂ symmetry

The symmetry results follow the mapping and formula-recovery theorems

Written solution Physical condition

A simple sufficient condition for zero field is

$$J_{AA}(r,r')=J_{BB}(r,r')\quad\forall r,r'\in \text{Site}.$$

Then $h_{\mathrm{eff}}=0$. At zero field the Ising Hamiltonian is invariant under

$$s(r)\mapsto-s(r),\qquad H[-s]=H[s].$$
Scope: A nonzero field still defines an Ising Hamiltonian, but explicitly breaks this global spin-flip symmetry.
Lean 4 zero field + spin flip
/-! ## Zero field and Z₂ symmetry -/

/--
A simple sufficient condition for zero effective field:
J_AA = J_BB pointwise.
-/
theorem effectiveField_zero_of_equal_interactions
    (JAA JBB : Site → Site → ℝ)
    (hEq : ∀ r r', JAA r r' = JBB r r') :
    effectiveField JAA JBB = fun _ => 0 := by
  funext r
  simp [effectiveField, hEq]

/--
An Ising Hamiltonian with h = 0 is invariant under
the global spin flip s ↦ -s.
-/
theorem ising_zeroField_spinFlip
    (J : Site → Site → ℝ)
    (C : ℝ)
    (s : Site → ℝ) :
    isingHamiltonian J (fun _ => 0) C (fun r => -s r)
    =
    isingHamiltonian J (fun _ => 0) C s := by
  classical
  have hpair :
      (∑ r : Site, ∑ r' : Site,
        J r r' * (-s r) * (-s r'))
      =
      ∑ r : Site, ∑ r' : Site,
        J r r' * s r * s r' := by
    apply Finset.sum_congr rfl
    intro r _
    apply Finset.sum_congr rfl
    intro r' _
    ring
  unfold isingHamiltonian
  simpa only [
    zero_mul,
    Finset.sum_const_zero,
    add_zero
  ] using congrArg (fun x : ℝ => x + C) hpair

Lean proves the zero-field condition and spin-flip invariance as separate theorems.

Formal conclusion and physical interpretation

Proved in Lean: On a finite lattice, the binary-alloy Hamiltonian is exactly equal, for every configuration, to an Ising Hamiltonian with the stated effective coupling, field, and constant. The file also proves zero-field spin-flip symmetry.
